# Deliverables (Owner Inbox) — Kunstpixel (kunstpixel.com)

Dette er museets **leveransemappe** hvor spesialiserte agenter legger ferdige, kvalitetssikrede dokumenter klare for **eierens/direktørens gjennomgang og godkjenning**.

---

### Mappens innhold:
* **Ferdige søknader:** Søknadstekster og kalkyler klare for innsending (f.eks. Sametinget, Kulturrådet).
* **Styre- og ledersaker:** Saksfremlegg, budsjettavvik og risikovurderinger.
* **Publikumsformidling:** Ferdige katalogtekster, veggtekster (50–90 ord) og audioguide-manus.
* **Tilsynsdokumentasjon:** Avvikslogger, utfylte vernerunderapporter og IK-Mat revisjonslogger.

---

### Regel for agenter:
Ingen agent skal utføre irreversible eksterne handlinger (publisere til web, sende søknader, bestille transport) før saken er levert her og signert av eier/direktør (*Human Sovereignty*).

---

### Innhold nå:
* **`firmafest_kunstprofil/`** — Kunstprofil-app for firmafesten (øvingscase). Seks spørsmål gir deltakeren én av elleve kunstnere fra `museum.db`, med et verk å se i samlingen. Åpne `index.html` i nettleseren. Bygges på nytt med `py -3.13 02_deliverables/firmafest_kunstprofil/bygg_data.py`.
