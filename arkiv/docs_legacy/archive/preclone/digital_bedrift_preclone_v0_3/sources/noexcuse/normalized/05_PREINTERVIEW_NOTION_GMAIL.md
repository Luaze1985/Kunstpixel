# Forarbeid før No Excuse-intervjuet

## Fire rammer som gikk igjen i Notion og Gmail

1. **Identitet - Hvem ønsker dere å være?**
2. **Struktur - Hva trenger dere av rammevilkår for å lykkes?**
3. **Menneskene - Hvem skal bidra til suksess?**
4. **Påvirkning - Hvordan få interne og eksterne kontakter til å støtte dere i størst mulig grad?**

## Notion - konkrete spørsmål teamet forberedte seg på

### Identitet
- Hva er den ene setningen som beskriver VIBS?
- Hvem er dere for?
- Hva er dere ikke?

### Struktur
- Hva skjer hvis hovedfinansieringen ikke går gjennom?
- Hvem gjør hva når Bjørn ikke er tilgjengelig?

### Menneskene
- Hvem er nummer to når Bjørn ikke kan møte?
- Hva skjer hvis Lars Gunnar faller ut?
- Hva er Christines og Thomas' konkrete leveranser?

### Påvirkning
- Hvem er de tre menneskene som kan gjøre størst forskjell nå, og hva konkret ber vi dem om?
- Hva er budskapet på Demo Day?

## Gmail - foreløpig bilde før intervjuet

E-posten 13.03.2026 beskriver Bjørn som gründer/daglig leder/relasjonsbygger og problemeier, Lars Gunnar som teknisk ansvarlig/prosessdriver/forretningsbro, og Lars Erik som operativt prosjektansvar med kunnskapsbase og intern struktur. Gjennomgående åpne punkter var:

- tydelig ansvarsfordeling per person
- redusere flaskehalsen via Bjørn
- sterkere teknisk ressurs internt
- første SMB-pilot og første kundekontakt
- finansiering og investoravklaring
- milepæler som holder motivasjon og framdrift oppe

## Forholdet til 60-punktsrapporten

Forarbeidet var bredere og mer operativt enn rapporten. Rapporten bryter de fire rammene ned i 60 mer spesifikke temaer. Derfor bør dette dokumentet brukes som **inntakskontekst**, mens 60-punktsbanken brukes som den strukturerte vurderingsmodellen.
