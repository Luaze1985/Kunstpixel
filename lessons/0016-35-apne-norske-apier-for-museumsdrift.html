35 Åpne Norske API-er & Datapunkter for Kunstpixel (Interne Tjenester, Drift & Samling)

Her er den fullstendige oversikten over 35 konkrete, åpne norske API-er og autoritative datapunkter som kan tappes direkte inn i Kunstpixels databaser (museum.db, kunstpixel_historikk.db og 05_data/governance/) med 0 KI-tokens. Katalogen dekker hele verdikjeden: fra kunstner- og verksregistre til intern drift, leverandørkontroll, tilsyn, bygningsvern og økonomi.

Kategori A: Kunstner-API-er, Samlingsforvaltning & Proveniens (Punkt 1–9)
# Kilde & Åpent API Hva slags datapunkt vi henter ut (0 tokens) Hvor det fylles inn i Kunstpixel
1 Norsk kunstnerleksikon (NKL)
nkl.snl.no/{navn}.json		 Autoritativ kunstnerbiografi, utdanning, stipendier, kollektivutstillinger og offentlige arbeider for norske kunstnere. museum.db → kunstnere
2 Store norske leksikon API
snl.no/api/v1/search		 Epokeartikler (f.eks. nyromantikk, sosialrealisme, Fleskum-kolonien) og fagfellevurderte verksanalyser. museum.db → verk.beskrivelse
3 KulturNav API (KulturIT)
kulturnav.org/api/search		 Autoritetsregister for kunstner-UUID, normerte teknikker (f.eks. tempera, pastell, koldnål) og materialterminologi. 00_felles/ordliste.yaml
4 DigitaltMuseum (DiMu Solr API)
api.dimu.org/api/solr/select		 Gjenstandsmetadata, eksakte mål (mm/cm), inventarnumre, påskrifter og historisk proveniens fra norske museer. museum.db → verk.proveniens
5 Nasjonalbiblioteket Katalog API
api.nb.no/catalog/v1/items		 Historiske utstillingskataloger, bøker, ISBN-numre og samtidige avisomtaler (fra 1880-tallet til i dag) for kunstverkene. historikk.db → utstillinger
6 Wikidata SPARQL Endpoint
query.wikidata.org/sparql		 Internasjonale autoritets-ID-er (ULAN, VIAF), ekte fødsels-/dødsdatoer, gravsteder, ektefeller og utenlandske museer som eier søsterverk. museum.db → kunstnere
7 Bono (Billedkunst Opphavsrett)
Tariff- og opphavsrettsdata		 Beregning av vernetid (70 år etter dødsår, åndsverkloven): Sjekker automatisk om kunstner er fri (Munch d. 1944 = fri) eller avgiftsbelagt (Bergman d. 1987 = vernet til 2058). museum.db → verk.status
8 Arkivportalen / Riksarkivet
arkivportalen.no (OAI-PMH)		 Historiske brev, korrespondanse og legatdokumenter knyttet til kunstnerne og gaver til museet. 04_knowledge/04_domain
9 Norvegiana / Europeana API
api.europeana.eu/record/v2		 Høyoppløselige bildelenker (IIIF-manifester), fargepaletter og lisensstatus (CC0 / Public Domain) for bruk i kampanjer. 05_data/samling.json

10 Brønnøysundregistrene (Enhetsreg.)
data.brreg.no/enhetsregisteret/api		 Sjekker automatisk at alle museets innleide leverandører (Securitas, AV-utleie, kunsttransport) har gyldig org.nr, ikke er under konkurs, og er MVA-registrert. historikk.db → hr_innleie
11 Brreg Regnskapsregisteret API
data.brreg.no/regnskapsregisteret		 Nøkkeltall (omsetning, driftsresultat, egenkapital) for kritiske underleverandører før museet inngår store rammeavtaler. 04_knowledge/risks
12 SSB Konsumprisindeks (KPI) API
data.ssb.no/api/v0/no/table/03013		 Eksakt indeksregulering av utstillingsbudsjetter, husleie og billettpriser fra 2010 til 2026 (realkroneberegning). museum.db → dagsbesok
13 SSB Museumsstatistikk API
data.ssb.no/api/v0/no/table/12362		 Nasjonale sammenligningstall (benchmarking): Besøk per årsverk, egeninntektsgrad og offentlig tilskudd per gjest i Norge. 04_knowledge/research
14 Norges Bank Valutakurs API
data.norges-bank.no/api/data/EXR		 Eksakte valutakurser (EUR, USD, GBP, CHF) for beregning av forsikringsverdier og innlån av kunst fra utenlandske museer. historikk.db → hr_innleie
15 Doffin / Anskaffelser API
dofin.no / data.norge.no		 Terskelverdier for offentlige anskaffelser (f.eks. 100 000 kr-grensen og EØS-terskler) når museet kjøper scenografi og vakthold. 04_domain/core/approval
16 Skatteetaten MVA-satser
data.norge.no (MVA-koder)		 Skiller deterministisk mellom museumsbillett (0 % MVA / unntatt), kafésalg på stedet (25 % MVA), take-away (15 % MVA) og katalogsalg (0 % MVA på bøker). museum.db → dagsbesok
17 Kulturdirektoratet Tilskuddsdata
kulturdirektoratet.no (Åpne data)		 Kravspesifikasjoner, rapporteringsfrister og tildelingskriterier for nasjonale museums- og prosjektmidler. 02_deliverables/soknader

Oppsummering: Hvorfor denne listen på 35 punkter endrer alt

Når du viser denne katalogen til elever eller ledere, forstår de umiddelbart at en bedrift ikke lever i et vakuum.

Ved å hente inn:
• Brønnøysundregistrene (for å sjekke leverandørene våre),
• Meteorologisk institutt (for å forstå hvorfor besøket spretter opp på regnværsdager og hvorfor klimaanlegget i Sal D jobber hardere),
• Mattilsynet & Lovdata (for å låse reglene i kaféen og vaktlistene), og
• KulturNav & Kunstnerleksikonet (for å berike samlingen),

...får du en levende, selvforsynt digital tvilling der 95 % av kunnskapen hentes gratis og feilfritt uten å bruke ett eneste KI-token!
