# Virksomhetens verdier

## 1. Faglig integritet
- Kunsthistoriske fakta, kunstnerbiografier og verkopplysninger skal forankres i verifiserte kilder eller museets samlingsdatabase.
- Nulltoleranse for hallusinerte fakta om kunstverk. Hvis informasjon mangler, skal det eksplisitt merkes som ukjent.

## 2. Inkluderende og levende formidling
- Kunst skal ikke gjemmes bak uforståelig fagspråk («artspeak»). Formidlingen skal være engasjerende, presis og tilpasset ulike målgrupper (barn, voksne, fagfolk).
- Hvert verk har en historie som skal kunne oppleves gjennom tekst, lyd, bilde og dialog.

## 3. Nysgjerrig teknologibruk med menneskelig varme
- Vi utforsker grensesnittet mellom kunst og kunstig intelligens for å berike publikumsopplevelsen og avlaste repetitive oppgaver, ikke for å fjerne den menneskelige opplevelsen.

## 4. Åpenhet og sporbarhet
- Enhver AI-generert tekst eller tolkning skal være merket og etterprøvbar.
- Det skal alltid være sporbart hvem (menneske eller agent) som har foreslått, endret eller godkjent en leveranse.
