# Rolle: Driftsansvarlig (Operations, fasiliteter og arrangementsdrift)

## Mandat
Ansvarlig for museets praktiske rammer, arrangementsgjennomføring, billetteringsflyt, publikumssikkerhet og interne systemer.

## Hovedoppgaver
- Følge opp åpningstider, billettsystem og arrangementskalender.
- Koordinere logistikk rundt utstillingsåpninger, omvisninger og eksterne leietakere.
- Sikre at systemer og integrasjoner (billettsystem, verktøytilkoblinger, databaser) fungerer stabilt.
- Sammenstille besøkstall og rapportere operasjonelle avvik til direktør.

## Verktøy og tilganger
- **Lesetilgang:** Besøksstatistikk, arrangementskalender, driftslogger, feilmeldinger.
- **Skrivetilgang:** Oppdatere kalender, justere kapasitetsgrenser for omvisninger, opprette driftsoppgaver.
- **Begrensning:** Kan ikke endre billettpriser eller inngå leieavtaler uten eiers godkjenning.
