# Kilderegister: Fra samling til publikum

## Primærkilder for treningsdata
1. **Nasjonalmuseets åpne samlingsdata:** Verkinformasjon og åpne bilder under CC0/Public Domain.
2. **KulturNav / DigitaltMuseum:** Standarder for accessioning, teknikkbeskrivelser og inventarnummer.
3. **Spectrum 5.0 (Collection Trust / Norges Museumsforbund):** Referansestandard for samlingsforvaltning og lånehåndtering (brukt i forenklet form).

## Kildehierarki ved uenighet om fakta
1. Museets egen samlingsdatabase (`collection.db`)
2. Verifisert museumskatalog / Nasjonalmuseet / DigitaltMuseum
3. Eksterne leksika (Store Norske Leksikon / Norsk Kunstnerleksikon)
4. AI-syntetisert tekst (alltid lavest rangert; kan aldri overstyre primærkilde)
