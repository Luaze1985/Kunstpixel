# Åpne spørsmål (Open Questions)

## Spørsmål 1: Python MCP Server vs lettbeint JSON-funksjonskall
- **Status:** Åpen
- **Problemstilling:** Bør samlings-pluginen pakkes som en fullverdig FastMCP Python-server via stdio, eller som en lettbeint Node/Python script-samling først?
- **Påvirker:** Kompleksitet ved oppsett for nye AI-gründere.

## Spørsmål 2: Lydgenerering for audioguide
- **Status:** Åpen
- **Problemstilling:** Skal audioguide-manuset kun leveres som tekst, eller skal vi koble inn et lokalt/skybasert TTS-verktøy (f.eks. Edge-TTS eller ElevenLabs) for å produsere ekte MP3-filer?
- **Påvirker:** Om mediehåndtering og audio-avspilling skal inngå i første demo.
