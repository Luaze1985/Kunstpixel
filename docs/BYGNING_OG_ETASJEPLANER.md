### Nøkkeldetaljer i etasjeplanen:
1. **Sal A (Sal 1):** Plassering direkte ved inngangssone med det karakteristiske **2 x 3 meter vinduet** som krever aktiv UV- og solavskjerming.
2. **Sal D (2. etasje):** Sikringssone med B60-ståldør og restverdiredning (RVR) Nivå 1 for *Skrik*.
3. **Universell utforming:** Heis og hovedinngangsrampe forbinder alle etasjer for rullestolbrukere og barnevogner.
4. **Logistikkåre:** Varelevering og kunstmottak i kjeller med heisforbindelse direkte opp til salene.
