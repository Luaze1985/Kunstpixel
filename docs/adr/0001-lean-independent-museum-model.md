# 0001: Forenklet, uavhengig SMB-modell for agenttrening og automatisering

## Kontekst
Målet med den syntetiske bedriften er å fungere som en praktisk test- og treningsarena for AI-gründere. Formålet er å øve på plugins, verktøytilkoblinger (MCP), automatiseringer og undervisningsopplegg. Et fullt offentlig byråkratisk museum (med offentlige anskaffelsesregler, KUD-rapportering og kommunale tilskuddsprosesser) ville innført unødvendig kompleksitet som bremser læring og eksperimentering.

## Beslutning
Kunstmuseet etableres operasjonelt som en **forenklet, uavhengig og ideell SMB-institusjon** (selvstendig stiftelse eller foretak med flate beslutningslinjer). Vi stripper bort tungt offentlig forvaltningsbyråkrati, og fokuserer domenelogikken rundt fire operative kjerneområder:
1. Samlingsforvaltning og verkmetadata (katalogisering, tilstand, tagging).
2. Utstillingsproduksjon og innholdskuratering (tekst, tema, utvalg).
3. Publikumsdialog og formidling (audioguider, undervisningsopplegg, henvendelser).
4. Operasjonell drift og oppgavestyring (arbeidsflyter, plugins og MCP-automatisering).

## Konsekvenser
- **Positivt:** Raskere iterasjon, frihet til å lage og teste plugins og automatiseringer uten å simulere offentlig saksbehandling.
- **Positivt:** Passer direkte til pedagogiske opplegg og praktisk undervisning for AI-gründere.
- **Avgrensning:** Lover om offentlige anskaffelser og statlige departementsrapporteringer simuleres ikke i denne iterasjonen.
