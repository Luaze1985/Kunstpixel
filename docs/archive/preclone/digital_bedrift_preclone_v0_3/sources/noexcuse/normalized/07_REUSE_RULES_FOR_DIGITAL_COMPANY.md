# Gjenbruksregler for den digitale bedriften

## Det vi kan gjenbruke generisk

- Fire rammer: Identitet, Struktur, Menneske, Påvirkning.
- 60 temaoverskrifter som vurderingspunkter.
- Mønsteret `spørsmål -> refleksjon -> sammenheng -> muligheter`.
- Omfang/effekt som enkel prioriteringsmekanisme.
- Ny gjennomgang senere for å dokumentere endring.

## Det som skal forbli VIBS-eksempeldata

- Alle konkrete VIBS-svar.
- Personnavn, roller, kapital-/investorhold, Demo Day, konsortium og markedspåstander.
- Konkrete anbefalinger som bare gir mening i VIBS-kontekst.

## Regel for agentbruk

En agent skal aldri presentere VIBS-svaret som «riktig svar». `SAMMENHENG` kan brukes som tolkningshjelp, men No Excuse understreker selv at metoden ikke har fasit eller score. For den syntetiske bedriften skal agenten derfor:

1. stille eller vise det rekonstruerte spørsmålet,
2. lagre bedriftens eget svar,
3. sammenholde svaret med tolkningsrammen,
4. foreslå muligheter,
5. skille klart mellom kilde, observasjon og anbefaling.

Dette gjør materialet egnet som en senere **ledelsesdiagnostikk-scenario-bank**, uten at vi kopierer VIBS som bedrift.
