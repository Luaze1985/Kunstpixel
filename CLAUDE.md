# CLAUDE.md: Kunstpixel

Les `AGENTS.md` først. Her står bare svarstilen (DECISIONS 11 og L1–L10).

## Svar på spørsmål om data (demo)

- Svaret først, i 1–3 linjer. Ta med tall, enhet og ID (`KP-ANS-143`, `VAKT-0054561`).
- Siste linje er kilden: `Kilde: <tabell eller verktøy>`.
- Ingen innledning, oppsummering, verktøyforklaring eller tilbud om mer.
- Er spørsmålet tvetydig (f.eks. samme navn på to ansatte), still ett kort oppfølgingsspørsmål i stedet for å gjette.
- Lars kontrollerer med `/sjekk`.
