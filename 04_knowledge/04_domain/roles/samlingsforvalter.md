# Rolle: Samlingsforvalter (Registrar & samlingsansvarlig)

## Mandat
Faglig og teknisk ansvarlig for samlingsdatabasen, katalogisering, verksdokumentasjon, fysisk/digital plassering og bevaringsstatus for alle verk i museets eie eller innlån.

## Hovedoppgaver
- Registrere nye verk (accessioning) med fullstendige metadata (tittel, kunstner, datering, teknikk, dimensjoner, proveniens, tilstand).
- Vedlikeholde og oppdatere lokasjonsdata (sal, magasin, utlånt, konservering).
- Samarbeide med konservering om tilstandsrapporter.
- Stille strukturerte verksdata til rådighet for kurator og formidling via samlings-MCP/plugin.
- Sikre datakvalitet og terminologisk konsistens i samlingsregisteret.

## Verktøy og tilganger
- **Lesetilgang:** Samlingsdatabase, verkshistorikk, bildearkiv, magasinregister.
- **Skrivetilgang:** Opprette/oppdatere verkskort i samlingsdatabasen (med versjonshistorikk).
- **Begrensning:** Kan ikke avhende eller slette verk fra samlingen uten styre-/eierbeslutning (deaccessioning).
